# Overview

Subha Choghadiya Muhurta is a small well-being extension that answers a simple daily question: which parts of today are considered favorable, and which should be treated with caution?

It calculates today's full Choghadiya periods from the selected city's sunrise and sunset, then labels each window as auspicious or inauspicious. Amrit, Shubh, Labh, and Char sit on one side. Udveg, Rog, and Kaal sit on the other. The active Muhurta stays highlighted so the current window is obvious at a glance.

Dedicated sections cover Abhijit Muhurta, Rahu Kaal, Kaal Vela, and Vaar Vela. Nothing is stored about the person using it. Location is used only to set local solar times.

![Extension popup showing the day's Choghadiya windows](/images/projects/subha-choghadiya/popup-day.jpg)

## What it does

- Full-day Choghadiya list with clear auspicious / inauspicious labels
- Live highlight for the Muhurta that is in effect now
- Abhijit Muhurta and Rahu Kaal called out on their own
- Instant retiming when the city changes

![City and settings views](/images/projects/subha-choghadiya/popup-city.jpg)

## Why it exists

Most Choghadiya tools are websites, PDFs, or apps that want an account. This one stays in the browser toolbar, stays offline-friendly after install, and keeps the UI to the day's windows only.

The listing is live on the Chrome Web Store under the well-being category.
