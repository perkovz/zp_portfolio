# The Challenge

Users of the Master Lock Vault Enterprise iOS app struggled to locate critical features — like refreshing the active locks list after a connection drop — leading to confusion and a spike in support queries. In just one week, I teamed up with iOS engineer Brandon Howard to tackle this issue head-on, designing a new onboarding tutorial alongside our regular sprint tasks.

![Lock in the awake state with the mobile app screen.](/images/projects/masterlock-tutorial/problem.png)

## My Contributions

As the Product Design Lead, I drove the UX effort by:
- 🎨 **Art Direction:** Crafted visuals and layouts within Master Lock’s branding guidelines.
- 🚚 **Design Deliverables:** Created user flows, wireframes, and polished assets for the tutorial.
- ✅ **Validation:** Tested the tutorial via UserTesting and in-person sessions to ensure clarity and accessibility.

Close collaboration with Brandon enabled rapid iterations, aligning design with development for a seamless rollout.

---

## Objectives

We aimed to:
1. 🧠 **Boost Comprehension:** Help users quickly understand key app functions. 
2. 📉 **Cut Support Load:** Reduce customer inquiries tied to navigation and feature use. 

---

## The Process

Our one-week sprint unfolded in four key steps:
1. **Day one - Research:** Analyzed user feedback to pinpoint pain points, like lock refresh confusion.
2. **Day two - Wireframing:** Sketched a logical tutorial flow to address these issues efficiently.
3. **Day three - Design (and Development):** Developed clear instructions, visuals, and interactive elements in Figma.
4. **Day four - Testing:** Ran guerrilla tests and UserTesting sessions, iterating based on real user input.
5. **Day five - Updates and Development:** By the end of the day, Figma files were updated, Jira ticket was closed, and feature branch was ready for the code review. 

![Many, many iterations.](/images/projects/masterlock-tutorial/process.png)
