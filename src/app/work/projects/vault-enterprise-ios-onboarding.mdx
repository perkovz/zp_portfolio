## Overview

I collaborated with an iOS developer to transform our app’s onboarding tutorial from initial conceptualization to deployment in just five days.

Many new users expressed confusion over key features in our Master Lock Enterprise Vault app, prompting us to create a clear, engaging guide that highlights what they need to know right from the start.

Our redesigned tutorial enhances user awareness and ensures a smoother onboarding process, making it easier for users to navigate and enjoy the app's features. Six months after its deployment, we haven't received any new complaints, which confirms the success of our redesign.

## Key Features

- **Addressing Immediate User Issues**: Built a set of modular, reusable UI components using React and styled-components in Next.js, focusing on accessibility and responsiveness.
- **Most Important Features First**: Integrated a theming system that allows easy switching and customization of color palettes, typography, and layout styles using CSS variables and Figma tokens.
- **Integrations**: Collaborated closely with designers by setting up a shared design library in Figma. This library was synchronized with the codebase, ensuring design handoffs were seamless and that design tokens remained consistent across both platforms.

## Technologies Used

- **Figma**: For creating and managing design assets and prototypes.
- **UserTesting**: For styling usability testing components with a modular, themable approach.
- **Crank Storybook**: For building an interactive live prototype on the Linux Yocto system.

## Challenges and Learnings

One key challenge was balancing the need for flexibility with the desire to maintain design consistency. The solution involved creating well-defined design tokens and establishing clear guidelines for when and how components could be customized. Additionally, setting up effective collaboration workflows between designers and developers using Figma and Git was a learning experience that greatly improved the process.

## Outcome

The design system is now actively used across multiple projects, leading to faster development cycles, fewer design inconsistencies, and improved collaboration between design and development teams. It has become a foundation for scaling our products efficiently while ensuring a cohesive user experience.
