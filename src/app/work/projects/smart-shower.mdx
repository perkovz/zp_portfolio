# Overview

The main challenge was to create an advanced shower GUI on an NXP board and 5” screen running on a Linux Yocto system. This task needed to be completed quickly and effectively. Tom and I tackled this problem head-on and figured it out in just five weeks!

![NXP MCIMX8ULP - SOM board, and 5” NXP BV screen.](/images/projects/shower-gui/nxp.jpeg)

---

## Key Features

- **Starting a Shower**: Start a shower from the home screen.
- **Choosing a Preset**: Users can customize their shower experience by saving preferred settings for temperature, water flow, and duration, allowing for a tailored and enjoyable shower each time..
- **Integrations**: The shower system seamlessly integrates with smart home devices, enabling voice control and automation for a convenient and hands-free experience.
- **Precise Water Temperature Control**: Users can achieve their ideal shower temperature with precise control, ensuring comfort and satisfaction while conserving water.
- **UI Interactions**: Test Cranks abilities to create complex UI interactions.

## Designing for Embedded Hardware

Finding the right design tool for prototyping on hardware was quite an adventure!

Layering and naming styles are determined by the software where they will be imported into.

![Component list prepared for Crank Import.](/images/projects/shower-gui/prepping-for-crank.png)

- I started by connecting the board to my laptop using HDMI and USB cables to mirror my Figma prototypes.
- Next, I dove into researching HMI design tools and landed on Crank. However, learning how to use Crank Storyboard wasn’t straightforward, especially since it’s not a free tool. I reached out to their sales team and successfully obtained a free license!
- The main reason I’ve choose Crank Storyboard were its embedded features, which, with a little bit of Lua scripting enabled me to create a prototype.

![Crank Storyboard dashboard.](/images/projects/shower-gui/crank-dashboard.png)

---

## Design solution

Once in Crank, I developed a comprehensive GUI prototype that included:

- **Intuitive Navigation**: Designed screens in Figma, focusing on easy access to Home, Presets, and other essential features.
- **Interactive Features**: Leveraged Crank to implement key flows and wrote Lua scripts to enhance user interactions with the interface.
- **Seamless Integration**: Collaborated with Tom to set up the NXP MCIMX8ULP - SOM board, using a 5” NXP BV screen running on a Linux Yocto system.

![Crank Storyboard demo](/images/projects/shower-gui/features_demo.mp4)
